# 시치미 개인정보 처리 안내

시치미는 "혼자일 때만 열리는 노래방"이라 무엇을 모으지 않는지가 기능의 일부입니다. 이 문서는 앱 안 「설정 → 기록과 개인정보 → 개인정보 처리 안내」와 같은 내용입니다.

## 1. 모으지 않는 것

- 이름, 연락처, 이메일, 계정 로그인 정보
- 위치(GPS·FusedLocation을 쓰지 않습니다. 내비에서는 「목적지까지 남은 시간」 숫자만 받습니다)
- 차 신호의 원본 기록(좌석·문·창문·기어 값은 노래방을 여닫는 데만 쓰고 저장하지 않습니다. 들킬 뻔한 순간에는 원인 종류(문·좌석·창문)와 시각만 남깁니다)
- 「전국 랭킹에 올리기」를 켜지 않았을 때의 마이크 소리(음높이 숫자만 계산하고 버립니다)

## 2. 이 차 안에만 저장하는 것

| 무엇 | 언제 | 지우는 법 |
|---|---|---|
| 주행·곡 기록(혼자 부른 시간, 곡, 들킬 뻔 원인·시각·그때 가사 한 줄) | 혼자 노래방일 때 | 설정 「기록 지우기」 |
| 노래 점수(곡별 점수, 고스트 대결 결과) | 노래 점수를 켰을 때 | 설정 「기록 지우기」 |
| 내 녹음(최고 기록을 낸 판의 목소리, 곡당 하나, 7분까지, AAC 32kbps) | 「전국 랭킹에 올리기」를 켰을 때만 | 점수 탭 「지우기」, 설정 「기록 지우기」 |
| 고른 고스트의 목소리 | 랭킹에서 「고스트로 겨루기」를 눌렀을 때 | 한 판이 끝나면 저절로, 설정 「기록 지우기」 |

## 3. 서버(Firebase Firestore)로 보내는 것 — 「전국 랭킹에 올리기」를 켰을 때만

| 경로 | 필드(서버 규칙이 이것만 받음) | 공개 |
|---|---|---|
| 곡별 최고 점수 `rank/{곡}/scores/{uid}` | 별명, 점수, 시각 | 누구나 읽음 |
| 주간 가장 빠른 대피 `escape/{주}/songs/{곡}/runs/{uid}` | 별명, 대피 시간(ms), 원인(문·좌석·창문), 시각 | 누구나 읽음 |
| 내가 「녹음 올리기」를 누른 녹음 `rank/{곡}/takes/{uid}` | 목소리(반주 없음), 점수, 곡 안 시작 위치, 길이, 시각 | 누구나 들음 |

- uid는 익명 로그인으로 받는 이 차의 임의 번호입니다. 사람을 알아볼 수 있는 정보와 묶이지 않습니다. 랭킹을 보기만 할 때는 익명 계정도 만들지 않습니다.
- 녹음은 켤 때 동의 창으로 한 번 더 알리고, 올리기 전에 미리 들어 본 뒤 직접 눌러야 올라갑니다.
- 지우기: 점수 탭의 「지우기」(그 곡 녹음), 설정 「서버의 내 녹음 모두 지우기」. 서버 규칙은 본인 uid 문서만 쓰고 지우게 합니다(`docs/firestore.rules`).

## 4. 마이크

혼자만의 노래방일 때, 노래 점수를 켰을 때만 엽니다. 동승자가 타거나 문·창문이 열리면 노래방과 함께 닫힙니다. 첫 사용 때 안드로이드 권한 창으로 묻습니다.
