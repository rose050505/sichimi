# 시연 순서 (본 영상 장면별 조작)

영상: **`docs/media/demo_main.mp4`** (2분 23초, 1920x1080 30fps, H.264·AAC, [브라우저에서 바로 재생](https://rose050505.github.io/sichimi/media/demo_main.mp4)). 처음 4.5초는 제목 카드이고, 오른쪽 아래에 지금 가수 목소리 상태를, 문·창문이 열리는 순간 앱 둘레에 노란 테두리를 덧씌웠습니다. 아래 표의 시각은 이 영상의 시각입니다(녹화 도구가 남긴 이벤트 기록에서 옮김).
가사 싱크 확인 영상은 따로 있습니다: `docs/media/demo_lyrics_sync.mp4` (59초, [검증기록](검증기록.md) 「시연 영상」 절).

화면 배치: 왼쪽 에뮬레이터(1440x810), 오른쪽 위 가상 콘솔 탭(8088)의 기어 칸, 그 아래 BODY 칸(문·창문). 콘솔에서 누른 자리에 노란 원이 퍼지고, 오른쪽 아래에 "콘솔 ▶ …"(노랑)·"앱 ▶ …"(하늘색)로 방금 한 조작이 3초 동안 뜹니다. 아래 띠에 장면 번호와 자막이 나옵니다.

**소리가 이 앱의 전부입니다.** 가수 목소리가 줄고 돌아오는 것을 들어 주세요. 영상 소리는 에뮬레이터 출력 그대로라, 화면이 바뀐 뒤 약 0.45초 뒤에 목소리가 바뀝니다(차 오디오 출력 약 0.25초 + 에뮬레이터가 PC로 소리를 넘기는 약 0.15초, 검증기록 「G2 오디오」). 영상에서 당기지 않았습니다. 후진 순간(1:01.2 바로 뒤) 녹음에서 빠진 소리 0.12초(틈 여섯 개)는 바로 앞 소리로 메웠습니다(시각은 그대로).

녹화 방법(도구, 소리 담기, 합치기)은 [녹화방법.md](녹화방법.md)에 있습니다.

## 직접 해 보기(준비)

```bash
~/Android/emulator/emulator -avd Pleos_Connect_v2.1 -no-snapshot -no-boot-anim -gpu host -memory 3072 &
adb wait-for-device
adb forward tcp:8088 tcp:8088
adb install -r apk/Graphite_Sichimi_release.apk
```

- 브라우저로 `http://127.0.0.1:8088/`을 열고 아래에 **DDS ONLINE**이 뜨는지 본다(탭을 닫으면 OFFLINE). 탭 없이 하려면 `python3 tools/console.py heartbeat &`.
- 콘솔 시작 상태: 운전석 착석, 동승석·뒷좌석 비어 있음, 문 넷 닫힘, 창문 넷 0%, 방향지시등 끔, 와이퍼 끔, **기어 P**.
  명령으로: `python3 tools/console.py seat driver on`, `seat passenger off`, `door front_right close`, `window front_left 0`, `turn off`, `wiper front Off`, `gear P`.
- 콘솔 페이지에서 쓰는 버튼: 오른쪽 아래 **BODY** 칸의 문(FL·FR·RL·RR, 누를 때마다 열림↔닫힘)과 창문(누를 때마다 0%↔100%), 오른쪽 위 기어 칸의 **P R N D**. 착석은 첫 화면에 버튼이 없어 「Emulation Controls」 창의 Seat Occupancy나 `console.py seat`로 바꾼다.
- **pm clear 직후에는 찍지 않는다.** 첫 노래방에서 「첫 무대」 칭호 카드가 떠 무대를 덮는다. 한 번 노래방을 거쳐 카드를 모두 닫은 뒤 찍는다. 들킬 뻔을 넘긴 횟수로도 칭호 카드(「시치미 3단」 등)가 뜰 수 있다.
- **예약 목록에서 아리랑을 누르면 대기열이 아리랑 한 곡이 된다.** 곡이 끝나면 재생이 멈추므로 Destroy·Wade의 「예약」을 눌러 「이어서 나올 곡」에 넣어 둔다.
- 내비: 남은 시간은 시간대에 따라 바뀐다. 「더몰트하우스 서핑시티」(330m)는 11/13 낮 3분, 11/14 0시 2분이라 밤에는 「한 곡 더」(3\~5분) 밖이다. 영상은 3\~5분 한가운데인 「뚜레쥬르 판교위든타워점」(1.2km, 0시 4분)을 썼다. 한 번 넣었다가 안내 종료해 두면 최근 목록 맨 위에 올라온다. 내비 화면이 꼬이면 `adb shell am force-stop --user 10 ai.umos.maps.android.navigation.app` 뒤 다시 연다. 앱이 **재생 중**이어야 내비 이벤트를 받는다.
- 「전국 랭킹에 올리기」는 끈 채로 둔다(서버에 시험 기록이 생기지 않게).

## 자동으로 돌려 보기(녹화 전 점검)

```bash
python3 tools/verify_scenes.py docs/evidence/scenes   # 장면 1~5, 8
python3 tools/verify_scene6.py docs/evidence/scene6   # 후진·방향지시등
python3 tools/verify_scene7.py docs/evidence/scene7   # 도착 몇 분 전 한 곡 더(목적지 「더몰트하우스 서핑시티」 낮 3분, 밤에는 2분이라 실패할 수 있음)
python3 tools/verify_arrival.py docs/evidence/arrival # 도착 1분 전 미리 시치미
```

`verify_scenes.py`(--keep-data 없이)와 `verify_scene7.py`는 앱 데이터를 지우고 시작한다(`verify_scene7.py --help`는 사용법만 찍고 지우지 않는다). 결과는 각 폴더의 `result.md`. 지운 뒤에는 위 「직접 해 보기(준비)」의 칭호 카드 주의를 본다.
