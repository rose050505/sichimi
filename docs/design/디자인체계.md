# 시치미 디자인 체계 「한밤 무대」

혼자일 때 보이는 화면(시치미 모드)을 하나의 체계로 묶는다. 동승자가 있을 때와 일반 상태의 화면은 기본 Pleos 다크 체계(`ui/Theme.kt`의 `Palette`)를 **그대로** 쓰고 이 문서의 어떤 것도 쓰지 않는다.

- 코드: `app/src/main/java/app/sichimi/ui/Night.kt`(색·모양·글자 토큰, 로고, 공통 부품). 기본 부품(`Components.kt`)은 고치지 않는다.
- 시안: `docs/design/mockups/`(A 한밤 무대, B 크림 그래파이트, 비교 `compare_A_B.png`). 고른 쪽은 A.
- 로고와 아이콘 원본: `docs/design/logo.svg`, `docs/design/app_icon.svg`.

## 0. 언제 이 체계를 쓰나

| 화면 | 언제 | 체계 |
|---|---|---|
| 주차 화면 틀(위쪽 로고 + 탭) | 혼자이고 ① 상태가 노래방이거나 ② 혼자만 보이는 탭(내 기록·점수·설정)을 보고 있을 때 | 한밤 무대 |
| 재생 탭 무대, 예약 목록 | 주차·혼자·노래방 | 한밤 무대 |
| 내 기록, 점수, 설정, 동의 창, 확인 창 | 혼자일 때만 보이는 탭 | 한밤 무대 |
| 곡 끝 점수 화면, 배지·미션·투어 포스터, 오늘 요약 띠, 리플레이 카드 | 주차·혼자일 때만 뜸 | 한밤 무대 |
| 주행 중 노래방 화면 | 주행·혼자·노래방 | 한밤 무대 색만(글·움직임·캐릭터·로고를 더하지 않음) |
| 그 밖(동승자가 있음, 일반 상태의 재생·예약 목록, 주행 중 일반 화면) | | 기본 Pleos 체계 그대로, 로고 없음 |

오늘 요약 띠는 내 기록 탭에서만 크게(아래 리플레이 카드와 함께), 그 밖의 탭에서는 한 줄로 접어 무대를 비운다. 리플레이 카드의 시치미는 작게 그리면 숨는 자세가 잘린 그림처럼 읽혀 "휴, 안 들켰다" 자세를 쓴다.

들킬 뻔한 순간(문·좌석·창문) 상태가 일반으로 바뀌면 재생 탭과 예약 목록은 그 프레임에 기본 모양으로 돌아간다(시치미 떼기).

## 2. 글자 크기 (Pleos 체계 그대로, `Type`)

| 이름 | 크기 | 쓰는 곳 |
|---|---|---|
| Headline | 56sp | 화면당 하나(배지 이름 카드, 큰 제목) |
| Title L/M/S | 40 / 36 / 32sp | 카드 제목, 순위 점수 |
| Body L/M/S | 30 / 28 / 26sp | 본문, 목록 |
| Label | 24sp | 보조 설명(가장 작음, 이 아래로 쓰지 않음) |
| 숫자 전용 Display | 64 / 88 / 160sp | 가사 지금 줄(64), 남은 점수·대피 시간(88), 곡 끝 점수(160). 숫자와 가사 한 줄에만 |

굵기는 제목 Bold, 숫자 ExtraBold, 본문 Normal. 글꼴은 시스템 글꼴(차량 Pleos 글꼴)을 쓴다. 로고만 직접 그린 글자다.

## 3. 간격과 모서리

- 간격: 8dp 단위 8 / 16 / 24 / 32 / 48 / 64. 화면 가장자리 32, 카드 안 32\~40, 카드 사이 24.
- 모서리: 칩·알약 = 높이의 절반, 조작(버튼·탭) 20 / 36(알약 탭), 카드 28, 대표 카드·무대·창 36, 조작부(dock) = 높이의 절반.
- 누르는 곳은 64dp 이상(주차), 주행 화면 버튼 136dp(기본 체계 그대로).

## 4. 카드 (무게 세 단계)

| 종류 | 모양 | 한 화면에 | 예 |
|---|---|---|---|
| 대표(Hero) | 왼쪽 위에서 `heroTop` 빛이 퍼지는 방사형 그라디언트, 테두리 `#4A2F66`, 모서리 36 | 하나 | 내 기록 맨 위 시치미, 점수 탭 내 최고 점수, 곡 끝 점수 화면 |
| 기본(Card) | `card` 바탕 + `line` 테두리 1dp, 모서리 28 | 여럿 | 투어, 미션, 랭킹 목록, 설정 무리 |
| 조용한(Quiet) | 바탕 없음, `line` 테두리 1dp | 아래쪽 덜 중요한 것 | 배지 판, 이번 달 통계, 비밀 차트 |

볼 순서 = 대표 → 기본 → 조용한. 위에서 아래로 무게가 가벼워진다.

## 6. 아이콘

- 24 격자, 선 2.2(둥근 끝), 면 아이콘은 같은 격자의 면. 기본 `AppIcons`를 그대로 쓰고 모자란 것(정보, 물음표, 별, 달, 빗방울, 유령)을 같은 규칙으로 더했다.
- 크기: 탭 28, 버튼 32, 칩 26, 메달 속 그림 48, 아이콘 버튼 34.

## 7. 로고 (앱의 얼굴)

- 「시치미」 글자 로고: 획 굵기가 같은 둥근 획으로 직접 그린 글자. ㅊ의 꼭지는 시치미의 상어지느러미 안테나(분홍), ㅁ 안에는 옆으로 흘끗 보는 두 눈(딴청). 기존 글꼴을 쓰지 않았다.
- 자리: 시치미 모드 주차 화면 왼쪽 위, 탭 줄 앞(높이 44dp). 일반 상태·동승자 화면·주행 화면에는 넣지 않는다.
- 앱 아이콘: 같은 언어로 다시 그림. 밤 무대색 바탕, 계기판 선 위로 떡 모양 시치미가 안테나와 두 눈만 빼꼼(숨는 중 자세), 금색 음표 하나. 얼굴만 보여 평범한 음악 앱처럼도 읽힌다.

## 9. 움직임

기어 P에서만, 지금 있는 것만: 가사 채움, 시치미 작은 흔들림, 곡 끝 점수 숫자 올라가기(1.2초), 숨기(0.3초). 눌렀을 때는 색만 바뀐다.

## 10. 주행 중 노래방 화면

기본 배치(곡 그림, 상태 칩, 제목, 가수, 버튼 셋, 136dp) 그대로에 색만 한밤 무대로: 바탕 `bg`, 음표 상자 대신 그 곡의 아트(정지 그림), 재생 버튼 분홍, 나머지 버튼 `raised`. 가사·점수·긴 글·움직임·캐릭터·로고를 더하지 않는다.

## 11. 닮지 않게

기존 노래방 업체·브랜드의 색 짝, 글자 모양, 점수판 모양, 캐릭터를 본뜨지 않았다. 메달·단상은 일반 기호이고, 색은 시치미 그림(크림 몸, 보라 무대 옷, 분홍 음표)에서 왔다.
